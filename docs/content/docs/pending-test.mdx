# 待测试

## Feature 分支能力整合

- 验证创作端直接使用后台公开系统渠道，图片、视频、音频、文本生成不再经过前台逻辑模型路由。
- 验证 Gemini Images 使用独立 `gemini-image` 协议；GlobalAiOpc、汇取云和 AIStarsLab 的图片/视频协议、默认参数与模型目录仍正常工作。AIStarsLab 模型目录已兼容 `defaultOption` 布尔值、可空描述和 `{ min, max, options }` 时长合同，并按默认线路去重同名模型。
- 验证汇取云 `sd2-mx933-720-*` 与 `sd2-mx933-720-fast-*` 文生视频使用 JSON，带图片、视频或音频参考时改用 multipart 文件上传；首尾帧、9 图/3 视频/3 音频、480P/720P、固定 5/10/15 秒及 `generate_audio` 参数均按官方合同生效，其他汇取云模型保持原协议。
- 验证 AIStarsLab 多图、图片加音频等参考生成不再被错误标记为不存在的 `reference_to_video` 操作；历史任务重试会按真实参考素材还原为 `image_to_video`、`extend` 或 `audio_to_video`。
- 验证 AIStarsLab 创建请求按官方合同上报必填字段：`channel` 取自模型目录线路编码（缺失时明确报错而不是发空值），`quality` 从声明档位选取，`mode` 按参考图数量推导为 `text2video`、`image2video` 或正好 2 张时的 `frames2video`。
- 验证 AIStarsLab 任务轮询按官方状态码 1/2/3/4 处理，结果从 `outputs` 数组读取，失败时使用 `errorMessage`；轮询间隔不低于 10 秒以免触发限流。
- 验证 `aistarslab-image` 已有后端生成路径，不再错误地落到通用 OpenAI Images 协议；图生图会上报参考图并受模型 `inputImagesMax` 限制，蒙版编辑明确拒绝。
- 验证 AIStarsLab 参考素材仅接受公网 URL，错误提示不再沿用汇取云文案。官方要求在提示词中用 `@图片1` 这类索引引用素材，当前未自动追加，需确认是否要由产品层补齐。
- 验证支持多个视频分辨率的后台模型可为各分辨率单独配置按次或按秒积分；任务预估、冻结和账单快照按实际分辨率命中，未单独配置的档位使用默认单价。
- 验证刷新或重新进入画布后可恢复本地运行任务、后端任务和延迟视频轮询，退出画布不会自动取消已提交任务。
- 验证管理员可配置响应拦截与 LibTV，画布可导入 LibTV 资源并正常预览，关闭设置时相关入口和请求明确失败。
- 逻辑模型相关表保留为历史数据兼容结构；新任务不再创建逻辑模型路由记录。

## 视频节点复制与模式判定
