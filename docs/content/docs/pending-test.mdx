## 团队共享素材库

- 验证个人文本、图片、视频、音频和 3D 模型可共享到团队素材库，浏览器临时媒体会先上传到后端资源存储。
- 验证其他登录账号可搜索、预览并从画布素材选择器插入团队文本、图片、视频和音频。
- 验证上传者和管理员可重命名、取消共享，普通成员不能修改他人共享素材。
- 验证素材库将“团队素材”作为独立一级列表展示，个人和团队文件夹互不混用。
- 验证个人与团队素材卡片都支持右键菜单和显式更多按钮；团队成员可复制文本或下载媒体，上传者和管理员可移动素材。
- 验证个人素材共享到团队时可先选择团队根目录或具体团队文件夹，确认后素材直接进入所选目录。
- 验证个人与团队文件夹可新建、重命名、删除；删除文件夹只把素材移回根目录。
- 验证取消共享不会删除上传者的个人素材和资源文件，且共享后私有资源不会匿名公开。
- 验证 SQLite 与 PostgreSQL 启动迁移会创建 `team_assets`、`team_asset_folders` 和 `team_asset_resources`。
