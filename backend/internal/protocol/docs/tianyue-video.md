# 天悦视频

天悦视频插件为 `tianyue-channel`，模型协议为 `tianyue-video`。渠道 Base URL 填写 `https://api.tianyue.xyz`，鉴权为 `Authorization: Bearer <API_KEY>`，密钥只由影策后端使用。

## 接口

{{OPERATIONS}}

创建和查询都使用 JSON，任务处理中每 5 秒查询一次。成功后下载响应中的视频并进入影策资源保存流程；不猜测或调用文档未声明的 `/content` 下载端点。

## 模型配置

在插件中心启用天悦渠道后，在系统渠道或自定义渠道选择“天悦视频”，手动添加模型广场中的实际模型名。按该模型的配置填写真实视频时长、分辨率、画幅、参考图片/视频/音频数量和大小限制，并独立设置影策价格。文档未给出完整模型目录接口，本插件不预置模型列表，也不保证通用“拉取模型”可用。

默认画幅和分辨率只展示本接口声明的枚举；通用时长及素材限制仅是可编辑起始模板，不代表天悦所有模型的真实能力。模型特定配置优先，管理员应在启用前核对；已有手工配置不会自动覆盖。

## 参数与计费

{{PARAMETERS}}

注意区分真实视频时长与上游计费用量：

- 模型名以 `-se` 结尾：按秒计费，`duration = video_duration = 真实秒数`。
- 其他模型：按次计费，`duration` 强制为 `1`，`video_duration` 为真实秒数。
- 影策的计费模式、自定义参数或元数据不能覆盖这条上游规则；不能把按次模型的 `duration` 设为视频秒数，否则可能多扣上游费用。
- 不发送 `seconds`、`resolution_name`、`images` 等其他渠道字段。必填分辨率仅接受 `480p`、`720p`、`1080p`（宿主数字档位会补 `p`）；缺少真实时长或分辨率直接失败，不猜值提交。
- `image_urls` 始终是数组，未连接图片时为 `[]`；是否要求至少一张图按模型能力配置校验。可选的 `video_urls`、`audio_urls` 无值时省略。
- 三类参考媒体必须是上游可访问的公网 HTTP(S) URL；宿主负责资源补传、公网 URL 转换和归属校验，不直接发送浏览器 blob、data URL 或本机文件。

## 状态与恢复

严格使用 `queued`、`in_progress`、`completed`、`failed` 四种状态；未知状态或返回不同任务 ID 会报错。任务 ID 优先读 `task_id`，其次 `id`。失败消息读取 `error.message` / `error.code` 等字段，失败响应残留的视频地址不会被消费。

成功时依次读取 `video_url`、`url`、`metadata.url`；没有视频地址则报告协议错误，不写入空素材。创建响应直接完成时也遵循相同校验。创建、查询和同源结果下载沿用渠道 Bearer 鉴权，跨域下载不向第三方发送渠道密钥。

后台或用户任务中心手动查询可复用既有上游 ID 恢复自动轮询，完成后热更新用户画布；恢复不会重提生成、重传参考素材或新预占积分。插件停用或未安装时拒绝生成及恢复，不降级为 OpenAI 视频协议。

## 官方资料边界

- 官方接口文档：<http://tianyue.iwmud.com/tianyue-api.html#video-create>。
- 本次仅适配视频创建与查询；文档中的 `-yb` 异步图片和脸部处理接口未纳入此插件。
- 模型时长、素材数量和可用清晰度仍以天悦模型广场为准；接口支持某字段不等于所有模型都支持它。

## 宿主运行时合同

- 插件负责视频请求、响应与状态映射，任务队列、权限、租约、计费和资源持久化仍由宿主管理。
- Base URL 可以填写服务根地址或带 `/v1` 的 API 根，宿主负责去重版本前缀；不能填写具体任务路径。
- 必填字段无效、出站校验失败、HTTP 非 2xx、无效 JSON、未知状态和完成但无结果都作为真实错误返回，不产生空素材。
- 恢复阶段只读取已有上游任务，不重新执行创建阶段校验，不使用失效的参考素材重新提交。
- 无 API、数据表或权限合同变更；新后端启动会注册内置插件，已停用插件的状态保持不变。需要与此前的任务恢复功能一并发布时，仍须完成其 Schema 11 迁移。
